# 05 官方谜题与设定辨析（第一季）

> 官方没回答的问题，就是同人小说最好的地盘。但**先分清哪些是坑、哪些是矛盾、哪些只是粉丝脑补**。
> 本文件只负责“列出问题 + 辨析矛盾”；**真假裁决在 [09 正史裁决书](09-正史裁决书.md)**，自造谜题在 [10 原创设定与谜题库](10-原创设定与谜题库.md)。

---

## 一、官方留下的真·未解之谜

### 1.1 蔓影术能不能解？

- 第一季末红眼对麦当施下“红眼蔓影术”，中术者会逐渐失去思想与意识，变成“影子人”。
- 官方给出的线索：唐·伍德在追捕红眼；笛亚愿意用黄金魔方交换。但**从未说明解法，甚至没说明“是否有解法”**。
- **可写方向**：解法需要“施术者本人”“另一个契约系自由者”“影子人的自愿牺牲”，或根本无解、只能延缓。已作出裁决，见 [09](09-正史裁决书.md)。

### 1.2 红眼·罗曼是谁？

已知碎片：

- 五色眼之一，地位仅次于主脑；
- 受“某人”委托阻止麦当去彩虹海（不是组织命令？）；
- 熊猫阿姨似乎认识他，他不承认；
- 方向感极差，把火星认成水星；
- 对麦当母亲辛夕娅的血脉异常重视。

**主流推测**：他与麦林/辛夕娅有旧；可能是被麦林救过的人、银河眼内部的“卧底”、或与麦当有血缘/师承关系。**官方零确认。**

### 1.3 辛夕娅（辛西娅）是谁？

- 第一季正片没有直呼其名，这个名字来自官方外围资料与电影版；背景几乎空白。
- 红眼“对她传给麦当的血脉相当重视”——暗示血脉本身是一种“资格”或“钥匙”。
- **可写方向**：她来自某个被银河眼灭掉的种族/家族；她的血脉能开启乌拉拉或彩虹海；她可能还活着。

### 1.4 五色眼的其余三位与“主脑”

- 第一季只登场红眼、蓝眼；紫眼、白眼、黄眼**三个席位全部空缺**，主脑从未露面。
- 这是最干净的留白：官方连人物都不给，我们填进去的任何人都不会撞车。
- **写作建议**：主脑不要写死。让它永远是“下一个更大的东西”。

### 1.5 彩虹海是真的吗？

- 全作的核心悬念。官方从未给出正面画面或确认。
- 麦林一行全员失踪，是“骗局”的最大证据；但雪流星、乌拉拉、魔鬼脚印的存在又说明“通往某处”的路是真的。
- **三种可选答案**：真存在 / 不存在但信念有力量 / 存在却被误解。本作的选择见 [09](09-正史裁决书.md)。

### 1.6 麦林还活着吗？

- 十年前率众进入黑洞，无一生还。
- 但：哈雷的“无限恒星号”据称能穿越黑洞；麦林是宇宙第二强者。
- **可写方向**：他在彩虹海内部、在时间错乱的区域、或被银河眼囚禁。

### 1.7 雪流星到底是什么？

- 星学会称：成群的雪流星在过去与现在的时间中穿梭，能把曾经遇难的人带回家。
- 它同时是“星体”“救援船”“时间机器”“死后世界”的混合体，官方没有解释机制。
- **写作价值最高**：它能合法地让死者归来，但必须付代价——这正是好故事的燃料。

### 1.8 被掳走的亚亚罗人

- 蓝眼带走了除咕咚外的所有亚亚罗人。他们现在在哪？做了什么实验？还有多少人活着？
- 官方完全留白。**这是最适合写“续作主线”的坑之一。**

### 1.9 银河眼到底要什么？

- 第一季：阻止任何人进入魔鬼脚印/彩虹海，控制星球、做实验。
- 但“为什么怕彩虹海”“实验的目的是什么”始终没说。
- **可写方向**：银河眼曾在彩虹海失去过什么；或者他们知道彩虹海的“愿望”有代价，封锁是一种保护。

### 1.10 第 27 集之后：官方的空白

- 第一季原定 52 集，只播出 26 集，红眼的蔓影术就是最后一帧。
- 有传闻第 27 集涉及“扑克牌主题的 BOSS”，并有若干未采用设定稿，**但从未播出，不可作为正典**。
- 电影版《风暴法米拉》系列曾试图接续，但其路线已被本作排除（理由见 [附录](../附录/非正史资料-风暴法米拉与冲出地球.md)）。
- **这几乎是官方送给同人的“续作开局”。**

## 三、粉丝主流推测（可用，但要自知）

1. **红眼与麦当有血缘/师承**：他对辛夕娅血脉的重视、熊猫阿姨的熟识、以及“受某人委托”而非组织命令。
2. **银河眼封锁彩虹海是为了防止“愿望”被滥用**：把反派写成“知道真相的守门人”，是二创常见且高级的处理。
3. **雪流星能复活死者但有代价**：星学会的使命因此才显得悲壮。
4. **米吉还活着**：一代米龙为妹妹才与海盗合作；米吉被联盟救走后再无音讯，正好留给续作。
5. **辛夕娅的血脉是“钥匙”**：能开启乌拉拉或彩虹海的某种权限。

> 使用建议：**一次只用一个推测**。同时启用三个以上，故事会变成解谜游戏，失去《星游记》的情感重心。

## 四、正典层级表

写小说时，遇到冲突按这个优先级取舍：

```
第一季 TV（1–26 集）         ← 唯一正典
   ↑
官方设定解说、主创采访        ← 补充（不违背正片时可用）
   ↑
百科／维基／粉丝 Wiki         ← 参考（常含电影版内容，需甄别）
   ↑
粉丝考据／二创惯例            ← 灵感
   ↑
《风暴法米拉》1–2 /《冲出地球》 ← 非正史，只作“传闻素材”（见附录）
```

**原则**：任何一句电影台词，若与第一季冲突，一律以第一季为准；若要借用，必须让它以“传闻”形式出现，并被角色怀疑。

## 五、“合法填坑”的三条原则

1. **填一个，留一个**：解开红眼身份的同时，埋下辛夕娅的新谜。读者要的是“继续追”的动力，不是答案清单。
2. **代价优先**：任何新能力、新道具、新复活，先想清楚“它拿走了什么”。《星游记》的力量体系是“交换”，不是“升级”。
3. **情感闭环**：每个谜题的答案，最后都要落回一个“人”的选择。彩虹海是不是真的不重要，重要的是**麦林当年为什么非要带所有人去**。
