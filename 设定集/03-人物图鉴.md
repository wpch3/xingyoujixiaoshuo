## A. 主角团

### A1. 麦当

| 项 | 内容 |
| --- | --- |
| 身份 | 地球少年，厨师；“红魔鬼”麦林之子；彩虹石自由者 |
| 年龄 | 13 岁（多数资料）／14 岁（新版百科）⚠️ |
| 生日 | 7 月 2 日【整理】 |
| 外形 | 棕褐色头发、红色中式立领上衣＋红短裤、腰间厨师围兜、右手腕红色彩虹石护腕 |
| 配音 | 阎萌萌（第一季） |

**性格**：超级自信乐观，体力超群，一根筋的天然呆；热血、固执、坚信正义；对男女之情完全迟钝。咕咚称他为“全宇宙第一没完没了”。

**能力**：彩虹石（强化系／食物系）——把身体或食物实体化、硬化，以烹饪手法战斗。

**招式谱**

| 招式 | 说明 |
| --- | --- |
| 中华肉包拳 | 招牌起手，实体化的肉包拳 |
| 肉包加速度 | 高速突进 |
| 中华大面饼 | 防御/压制 |
| 拉面金箍棒 | 伸缩长棍 |
| 肉包冲天炮 | 气压远程炮，秒杀卡利亚 |
| 高压锅肉包拳 | 借空气接收器压缩空气，一击摧毁月树；发动时不能呼吸，过后全身无力 |
| 肉包套餐·连发 | 连打 |
| 百万爆米花 | 大范围爆裂（蔓影术状态下威力异常） |
| 肉包陀螺弹 | 旋转突进 |
| 中华炸元宵 / 大元宵 | 电影版招式 |

**经历线**：幼年与父亲拉钩约定“在彩虹海见” → 地球禁飞下造飞船 → 遇咕咚 → 飞出地球 → 月球救咕咚 → 火星夺魔方 → 天王星救笛亚、击败克拉 → 泰坦星补给 → 火星格斗螺旋 → 罗罗乌篇 → 被红眼施下蔓影术（第一季终，本作起点）。

**台词**
> “拉过勾的事，就一定要做到！”
> “不管输赢，打完不许记仇哦！”
> “给我，高高飞起来啊！”
> “那又怎样啊！”

**写作提示**：麦当的“笨”是**选择**，不是智商。他能在关键时刻说出最准的一句话，但绝不算计。写他时，让他**先行动，后思考**；让他对朋友的痛苦异常敏感，对自己的伤毫无概念。

### A2. 咕咚·萌西

| 项 | 内容 |
| --- | --- |
| 身份 | 亚亚罗星球国王；“国王号”船长；主角团驾驶员与补给 |
| 年龄 | 未知（变兔子前 13 岁） |
| 外形 | 兔子形态（人形是正太，正片未给正面镜头）；王冠 |
| 配音 | 郝幽玥（第一季） |

**性格**：自大、胆小、爱面子、毒舌，但重情；说话爱带“嘞”；讨厌被叫兔子。逐渐从“吉祥物”长成真正的国王。

**能力/道具**

- 萝卜咔嚓腿（自称绝技）
- 怪物泡面：收纳怪物，可合体——**奶昔鸡**、**龟龟熊**
- 1 分钟隐身药丸
- 装死（“国王秘技”）
- “百分之百逃脱率”（并不值得自豪）

**经历**：父母是星球英雄，幼年继位，实权在大臣约士亚手中 → 为筹“不死药”研究经费，卖掉亚亚罗的**空间跳跃装置** → 星球被海盗/银河眼攻破，臣民把他变成兔子送出 → 赴月球求嫦娥 → 被麦当的导弹打落地球 → 同行 → 月球得知真相 → 决定救亚亚罗 → 第一季终：与麦当、笛亚同行，寻找进入魔鬼脚印的驾驶员。

**台词**
> “我就是伟大的亚亚罗国王——咕咚·萌西！”
> “萝卜嘞！”
> “你才是兔子嘞！”
> “他可是连不死月树都能打倒的，全宇宙第一没完没了！”

**写作提示**：咕咚的所有笑点都建立在**自卑**上。他越夸张地自称国王，越说明他怕自己不是。写他的高光时刻，要让他**用最怂的姿态做最勇的事**。

### A3. 笛亚（Di Ya）

| 项 | 内容 |
| --- | --- |
| 身份 | 星学会会长盖亚的孙女；星学会唯一幸存者；最后的星学家；彩虹石自由者 |
| 年龄 | 13 岁 |
| 外形 | 蓝色长发、绿色发饰与服饰；总是带着微笑 |
| 配音 | 山新 |

**性格**：冷静、聪慧、有谋略；习惯用微笑掩盖创伤；战斗时负责解说招式与战术，是团队的智囊。悲观底色，但在麦当影响下重新相信。

**能力**：彩虹石（契约系）——**空间契约**

| 招式 | 效果 |
| --- | --- |
| 空间契约·交换 | 与视线内的物体交换位置 |
| 空间契约·凝固 | 中断传送、锁死双方空间，同归于尽型 |
| 空间契约·壁垒 | 空间防御 |
| 空间契约·禁闭 | 空间囚笼 |

**经历**：父母在护送黄金魔方给星际联盟途中被克拉击杀 → 爷爷盖亚与星学会被血洗 → 被面包圈马戏团菲利团长收养 → 火星遇麦当 → 用假魔方换真魔方、独赴天王星 → 启动空间吞噬失败、失去彩虹石力量 → 被麦当拉回 → 恢复能力、合力击败克拉 → 同行寻找雪流星 → 第一季终：与麦当、咕咚继续向魔鬼脚印前进。

**台词**
> “星学家的使命，就是让人们不再恐惧天空，为每个旅行的人照亮回家的路。”
> “相信奇迹的人，和奇迹一样了不起。”

**写作提示**：笛亚的成长不是“变强”，是“允许自己被人救”。她每一次计算都是为了**独自去死**；写她的转折，就写她第一次把计划交给别人。

### A4. 米龙（二代）

| 项 | 内容 |
| --- | --- |
| 身份 | 画家、格斗家；“米龙”之名的继承者；**非自由者**（无彩虹石） |
| 年龄 | 20 岁上下（比麦当大几岁） |
| 外形 | 黄色外套、墨镜、高度近视；三根手指留着画画 |
| 配音 | 张杰 |

**性格**：沉默、执拗、羞耻感极重；以“成为能真正守护他人的英雄”为目标；对“米龙”这个名字既崇拜又憎恨。

**能力**：八极天（传说中最强格斗术）

```
一式：暴足、逐空
二式：破鞘、剑闪、刀乱雷、刀卷云
三式：土笼域、落土飞岩
四式：凝冰刃、千冰旋斩
五式：焚步
六式：焚场
七式：碎霸
八式：流星强袭
米龙传说·刀截剑：金色天际线（一天只能用一次）
```

**经历**：孤儿，童年被黑旗奴役 → 被一代米龙所救 → 目睹偶像向海盗下跪、承认不会格斗 → 一代米龙为护他而死 → 继承其名、外套与墨镜，赴八极星苦修九年 → 在格斗螺旋以“冒牌米龙”身份击败马马卡 → 得知沙丁真正目标是战神之子 → 放走格格斯 → 被沙丁“第二大脑”控制下跪 → 被麦当与罗罗乌人救下 → 独自离开，去向不明。

**台词**
> （一代米龙的遗言，也是他的信条）“替我活下去吧，活到那个……弱者也能幸福的时代。”

**写作提示**：米龙是“用谎言长出来的真英雄”。他的战斗必须**疼**——八极天是肉体凡胎练出来的，不是天赋。写他出手，要写骨头、血、呼吸和近视眼镜后的眼神。

## B. 麦林的同行者与地球众生

### B1. 麦林（红魔鬼）

- **身份**：麦当之父；十年前向全宇宙宣告彩虹海的男人；宇宙第二强者【整理】。
- **外形**：红色风衣，高大，强得可怕。
- **经历**：与哈雷为好友，资助其造出“无限恒星号”；率全宇宙冒险者冲入黑洞，全员失踪；被后人称为“红魔鬼”，彩虹海被视为史上最大谎言。曾只身对抗黑旗七大舰队与银河眼。
- **写作提示**：**永远不要让他正面出场太久**。他是“缺席的父亲”，是整部作品的光源与黑洞。任何关于他的闪回都必须短、暖、然后断掉。

### B2. 辛夕娅（辛西娅）⚠️

- **身份**：麦当的母亲。姓名由电影版披露，第一季正片未直呼其名——本作沿用该名并重设其来历（见 [09 裁决书](09-正史裁决书.md)）。
- **设定**：背景极少；红眼·罗曼对她传给麦当的血脉异常重视，似乎“血脉”本身有秘密。
- **写作提示**：官方留白最大的角色之一，适合做长篇核心谜题（她是谁？为何红眼在意？她是否与银河眼/彩虹海有关？）。

### B3. 熊猫阿姨

- **身份**：宇宙大饭店老板娘；芸豆的母亲；麦林的旧识；疑似麦当的师父。
- **外形**：总穿胖大的熊猫服，却身手敏捷；极喜欢可爱的东西。
- **能力**：深不可测的体术；曾**只身摧毁银河眼地球总部**。
- **写作提示**：全作最强的“日常伪装”。她越是滑稽，越要让人怕。写她的战斗，要用**静**——打完才让人发现她已经动过。

### B4. 熊猫阿姨的丈夫

- **身份**：麦林好友；十年前同行前往彩虹海；宇宙第三强者【整理】。
- **写作提示**：与麦林一同失踪的“另一个父亲”。他的存在让熊猫阿姨的守店有了重量。

### B5. 芸豆（包子妹）

- **身份**：宇宙大饭店店主的女儿；麦当的青梅竹马。
- **名字**：正片未给名，粉丝称“包子妹”；本作采用**芸豆**。
- **经历**：父亲随麦林去了彩虹海；多次帮麦当离开地球；第一季末与熊猫阿姨留在地球。
- **写作提示**：她是“被留在地球的那一半人生”。写续作时，让她成为地球上的联络人/记者/船长都很成立。

### B6. 哈雷

- **身份**：地球最伟大的工程师；“无限恒星号”设计者；哈马的哥哥；麦林的坚实伙伴。
- **经历**：受麦林资助完成无限恒星号，一同前往彩虹海失踪。
- **台词**（哈马转述）：“不可能这三个字，你已经说得太多了。”

### B7. 哈马

- **身份**：哈雷的孪生弟弟；飞船坟场主人；后与银河眼合作。
- **经历**：为替哥哥筹钱参加无规则飞行赛，飞船中弹，半身瘫痪 → 怨恨哥哥与所有会飞的东西 → 把造船厂改成飞船坟场 → 被麦当击败 → 发现哥哥早已修好他的“恒星号”，一直在角落等他。
- **写作提示**：全作最好的“反派即伤者”。他的轮椅/义肢是主题道具。

### B8. 嫦娥

- **身份**：月球炼丹师；银河眼卧底。
- **能力**：彩虹石（转化）——把药力变成攻击力。
- **经历**：受咕咚雇佣研制“不死药”，实为引诱他上钩 → 要把咕咚投入月树炼成不死药 → 月树被毁 → 被咕咚用兔子药变成兔子，逃出月球，扬言“再见面时就是解药炼成的时候”。
- **写作提示**：她是“温柔的刀”。下次登场时，她既是仇人，也是唯一能解兔子药的人——这种两难非常好用。

### B9. 约士亚

- **身份**：亚亚罗内阁大臣，掌握实权；把王冠戴到年幼咕咚头上的人。
- **行为**：为保护咕咚，亲手让他吃下兔子药、把他送出星球，自己留下面对灭亡。
- **台词**
> “王冠会让戴上它的人高人一头，是地位的象征。但王冠真正的意义是，当灾难从天而降时，我会为你们抵挡一切，永远让你们只看到金色的希望。”

## C. 银河眼

### C1. 主脑

- 身份不明、性别不明、从未露面。五色眼之上的最高存在。**写续作时最值得保留的神秘**。

### C2. 红眼·罗曼

| 项 | 内容 |
| --- | --- |
| 身份 | 五色眼之一，地位仅次于主脑；后背叛银河眼 |
| 外形 | 红眼、黑衣；从不轻易用手 |
| 能力 | 契约系·影子契约：影子出手、影子冲击、影兽、**红眼蔓影术**、**蔓影术·吞噬** |
| 弱点 | 认路能力极差，曾把火星认成水星；讨厌绕路，会直接拆墙 |

**经历**：受“某人”委托阻止麦当去彩虹海 → 一路追击 → 第一季末对麦当施下“蔓影术”。此后的空白由本作填补（见 [09](09-正史裁决书.md)）。

**关系**：熊猫阿姨似乎认识他（他不承认）；他对辛夕娅的血脉极为在意；与麦当“有很深的渊源”⚠️。

**台词**
> “对付你，根本不需要用手。”

**写作提示**：红眼是全作最大的“未解之谜”载体。**不要轻易揭他的底**。让他每次出场都解决一个悬念、又埋下两个。

### C3. 蓝眼

- **身份**：五色眼之一；克拉的上级；特攻/战争部门主管。
- **外形**：满口金牙，不爱说话，戴鹦鹉帽替自己发言。
- **能力**：音波系（灵力系），弹竖琴。
- **行为**：下令夺回乌拉拉；带走除咕咚外所有亚亚罗人。
- **写作提示**：把“暴力”外包给鹦鹉和部下，是极好的反派质感。

### C4. 紫眼 / 白眼 / 黄眼（席位空缺）

- 第一季只确立了“五色眼”这个建制，并让红眼、蓝眼登场；其余三席**没有人物、没有能力、没有名字的正式说明**。
- 本作保留三个席位，人物与能力自行设定（见 [10 原创设定与谜题库](../设定集/10-原创设定与谜题库.md)）。
- **写作提示**：空席位是最好的悬念。不要一次填满；每揭开一席，都应该是某条人物线的终点。

### C5. 克拉

- **身份**：银河眼干部，隶属特攻部门，蓝眼部下；冷酷杀手。
- **能力**：钢化身躯、爆破术、炼钢术、锤/重锤/火药锤、黑火枪/飞火枪、战争武装、**火药云**（可炸掉半个星球）；宠物**火药鸦**（羽毛受重击会爆炸）。
- **罪行**：八年前屠灭星学会（杀尽除笛亚外的所有成员）；追杀笛亚；摧毁面包圈马戏团。
- **结局**：天王星被麦当击败，被鼹鼠部队救走，生死不明。
- **写作提示**：他是“纯粹的恶”，但恶得有美学——钢铁、火药、鸦。不要给他悲情背景，让他就是冷的。

### C6. 赛璐珞

- **身份**：银河眼地球经理人。
- **性格**：极度自恋，讨厌别人打断他说话。
- **实力**：极弱，靠怪物泡面作战，泡面后被咕咚抢走。
- **写作提示**：银河眼官僚体系的喜剧切片。适合写“体制内的废物如何作恶”。

### C7. 大头钉

- 银河眼量产战斗单位，穿不露脸的紧身衣，口头禅“嘿哈”。可听命于任何等级更高的单位。

### C8. 鼹鼠部队

- 银河眼基层部队，擅长地下突袭/钻地。天王星篇偷袭麦当。

## D. 星际联盟

### D1. 唐·伍德（唐伍德）

- **身份**：星际联盟长官/执法官；彩虹石自由者；背景极深。
- **外形**：墨镜、海滩服，审美与常人相反（曾说笛亚是“丑丫头”）。
- **能力**：雨伞摇点——**二十四节气**、**六道轮回**（天府/天梁/天机/天同/天相/七杀，按骰子点数决定招式强度）。
- **行为**：为追捕卡利亚到火星，救下麦当一行；因他们不配合而通缉；与笛亚交易（帮解蔓影术 ↔ 交出黄金魔方）；追捕红眼失败。
- **写作提示**：他是“体制里还活着良知的人”，但良知有价格。写他时永远给他一个**程序上的理由**。

## E. 星学会

### E1. 盖亚

- **身份**：星学会会长；笛亚的祖父；黄金魔方守护者。
- **信条**：“人类就是靠不断冒险才能走到今天。”“坚信希望之光穿透绝望。”
- **结局**：星学会被血洗时拼死守护魔方；具体生死在正片中未明（多数资料视为已故）⚠️。

### E2. 笛亚的父母

- 护送黄金魔方前往星际联盟途中，被克拉的飞船击落身亡。笛亚创伤的源头。

## F. 黑旗与海盗

### F1. 阿西欧

- **身份**：黑旗盗贼团海盗，策划并参与米龙的骗局。
- **行为**：因米龙把电影收入匿名捐给战争孤儿而与之反目；以无名少年（米龙二代）要挟，逼米龙当众下跪，制造“下跪的米龙”。
- ⚠️ 部分资料把“金牙＋鹦鹉帽”的设定安在他身上，实为与蓝眼混淆。

### F2. 卡利亚

- **身份**：火星盗贼团首领；磁力自由者；曾与麦林对战被击败。
- **能力**：万能磁力、南极风暴（操纵一切金属）。
- **性格**：贪婪。“打断我数钱，是要用命来还的。”
- **结局**：被麦当“肉包冲天炮”秒杀；后试图与沙丁合作，失败逃走。

### F3. 沙丁

- **身份**：五角军团首领。
- **能力**：彩虹石（森蓝）“第二大脑”——暂时控制一个人的躯体；**对自由者无效**。
- **野心**：控制拥有金色牛角的罗罗乌王 → 召唤战神之子 → 征服宇宙。
- **结局**：阴谋败露，控制米龙下跪未遂，被麦当与罗罗乌人赶走。

### F4. 电鳗弗兰克

- 五角军团第五人，电系攻击。主角团逃出格斗场后遭遇。

### F5. 泥浆骑士

- 沙丁手下，穿盔甲的泥浆；麦当第一场因盔甲内是泥浆而被抱住、无法作战而败。

## G. 罗罗乌族

### G1. 大战神库撒

- 大罗罗族统帅，“战神”；曾率族侵略数十个星系；宇宙第四强者【整理】。

### G2. 格格斯

- **身份**：罗罗乌族的“战神之子”，老罗罗乌王选定的继承者。
- **特征**：没有战斗潜质，只有一只金色牛角，却拥有全族都没有的能力——**微笑**。
- **意义**：罗罗乌和平未来的象征；米龙二代在他身上看到当年的自己。
- ⚠️ 名字在不同资料中亦作“格格斯”。

### G3. 马马卡（厄运马马卡）

- **身份**：罗罗乌最强战士。
- **战绩**：上次大战末期，上千人的军队遇到他一人，全部放下武器投降。
- **能力**：战神兵器（战锤、臂铠）；与贝贝里可合体为“战神守护者”，召唤角盾/大角盾。
- **性格**：骄傲、护族，最终为保护格格斯而战。

### G4. 贝贝里

- 罗罗乌战士，马马卡的搭档，可与马马卡合体。

### G5. 罗罗乌王

- 格格斯之父（⚠️ 一说为母/王后传承）；临终把金色牛角传给格格斯，而非最强的马马卡。

### G6. 乔里弗一世

- ⚠️ 见于配音表的角色名，身份不明（或为罗罗乌王/某星球君主）。写作时建议回避。

## H. 八极天

### H1. 八极天祖师

- 宇宙最强格斗术“八极天”的创始者；宇宙第一强者【整理】。正片未正式登场。

### H2. 米龙（一代）

- **身份**：被全宇宙奉为英雄的格斗家——**其实是个手无寸铁、弱不禁风的普通人**。
- **经历**：与妹妹米吉在米多星种花田 → 罗罗乌战争毁掉家园，他因恐惧抛下呼救的妹妹逃走 → 妹妹被星际联盟救走、音讯全无 → 为让妹妹听见自己的名字，与黑旗合作、拍电影、伪造英雄身份 → 捐款给孤儿触怒海盗 → 被逼当众下跪，承认不会格斗 → 为救无名少年（米龙二代）被打成重伤而死。
- **台词**
> “在我背后，微笑的活下去吧。”
> “替我活下去吧，活到那个……弱者也能幸福的时代。”
> “世界上最美的，是人的微笑啊！把所有人都踩在脚下，才能登上的顶峰，还能看到什么风景？”

### H3. 米吉

- 米龙一代的妹妹；战争中与哥哥失散，被星际联盟救走。本作可自行决定她是否登场、以什么身份登场（见 [10](../设定集/10-原创设定与谜题库.md)）。
