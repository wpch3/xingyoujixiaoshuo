## 一、航线总览

《星游记》的地理不是“星图”，而是**一条被封锁的逃亡路线**。主角每前进一步，可用的资源就少一分，追兵就多一分。

```
【起点】地球（禁飞·唯一飞船）
   │  突破电网与导弹
   ▼
【第一站】月球（嫦娥·月树·兔子药）
   │  拿到“国王号”，确认亚亚罗已亡
   ▼
【第二站】火星·塔尔西斯（航线已被联盟关闭）
   │  转黄泉湾黑市
   ▼
【第三站】火星·黄泉湾（卡利亚盗贼团 / 黄金魔方）
   │  笛亚被克拉掳走
   ▼
【第四站】天王星（星学会遗址 / 乌拉拉 / 雪原）
   │  击败克拉，取得魔鬼脚印坐标
   ▼
【插曲】泰坦星（燃料耗尽·泰坦水·史前巨兽）
   │
   ▼
【第五站】火星·塔尔西斯（找驾驶员）
   │  咕咚被绑 → 罗罗乌族 → 格斗螺旋
   ▼
【第一季终点】火星·罗罗乌农田
   │  红眼降临，蔓影术
   ▼
（此后为本作自撰区）
   ▼
【第六站】水星附近·魔鬼脚印入口（坐标＋船＋驾驶员）
   │  天然虫洞航线
   ▼
【终点】歌罗星系（巨型黑洞）
   │
   ▼
【传说】彩虹海
```

> **写作提示**：这条路线有一个漂亮的节奏——**每一站解决一个“资格”问题**：地球给你“船”，月球给你“同伴”，火星给你“坐标”，天王星给你“真相”，泰坦星给你“补给”，罗罗乌给你“人”（驾驶员）。续作可以套用同样的“一站一资格”结构，但**不要让主角一次凑齐**：三条件每满足一个，就应该引来一个新的敌人。

## 二、太阳系：内圈

### 2.1 地球

**基调**：废土化的旧城 + 被管制的天空。

| 地点 | 说明 | 剧情功能 |
| --- | --- | --- |
| **老城区第七街** | 麦当生活的街区，市井、拥挤、烟火气 | 日常与追捕的发生地 |
| **宇宙大饭店** | 熊猫阿姨开的饭店，芸豆是店主之女；麦当在此帮厨 | “家”的象征；地下据点 |
| **飞船坟场** | 哈马把哥哥的造船厂改成的飞船墓场，设有焚毁炉、碎渣机器人、龟龟熊群 | 第 2–5 集主舞台 |
| **银河眼地球总部** | 地球禁飞令的执行机构 | 被熊猫阿姨只身摧毁 |
| **禁飞区/天盾** | 布满电网与导弹的天空 | 第 5 集“冲出地球” |

**氛围细节**：风筝、纸飞机、被击落的飞行器残骸、举报电话、黑市零件摊、拆船工人。

### 2.2 月球

| 地点 | 说明 |
| --- | --- |
| **月宫／炼丹房** | 嫦娥的居所，充满药炉、符咒与机械 |
| **月树（不死树）** | 无法从外部打开，能把投入者炼成“不死药” |
| **月兔群** | 月球的原住民/实验品，嫦娥的帮凶与受害者 |
| **暗面** | 月球的阴暗面，藏有亚亚罗灭亡的真相 |

**剧情功能**：把“同伴的来历”一次性揭开；把咕咚从喜剧角色变成悲剧角色。

### 2.3 火星

**基调**：frontier town（边境镇）＋ 地下黑市 ＋ 隐秘农田。

| 地点 | 说明 | 剧情功能 |
| --- | --- | --- |
| **塔尔西斯** | 火星的星际港/航线站点；海盗、水手、驾驶员聚集 | 找驾驶员、被通缉、遇唐·伍德 |
| **黄泉湾** | 海盗聚集的港湾城市，赌场、船坞、拍卖行 | 夺黄金魔方（第 9–10 集） |
| **格斗螺旋** | 地下竞技场，三局两胜、生死战；观众下注 | 第 22–26 集主舞台 |
| **火星深处农田** | 罗罗乌族隐居地，种田、养麦麦羊 | 反差最强的一幕：最好战的种族在种地 |
| **面包圈马戏团（旧址）** | 菲利团长的马戏团，被克拉摧毁 | 笛亚的“第二个家” |

### 2.4 天王星

| 地点 | 说明 |
| --- | --- |
| **星学会遗址** | 被血洗的天文台/图书馆；藏有“乌拉拉” |
| **乌拉拉** | 巨型星系望远镜／信号接收装置；启动时整颗天王星发出**眼睛形状的光芒** |
| **冰雪迷宫** | 天然冰洞与迷宫，土著指引才能通过 |
| **雪原** | 无边雪地，奶昔鸡群与“白色野兽”的栖息地 |
| **密室** | 藏魔鬼脚印坐标的房间，需星学会血脉/权限开启 |

**剧情功能**：全剧情感最高点（第 12–18 集）；笛亚的创伤与重生。

### 2.5 泰坦星

| 地点 | 说明 |
| --- | --- |
| **原始森林** | 巨型植物、毒气、史前生态 |
| **甲烷海／泰坦水** | 可作替代燃料；剧中有开采痕迹——本作设定为“被银河眼大规模抽走”，作为原创伏笔（见 [10](10-原创设定与谜题库.md) O 系列） |
| **巨兽巢穴** | 独霸唯一水源的史前巨兽 |
| **“第二个麦当”** | 镜像式对手/幻象，第 19 集的核心谜题 |

### 2.6 水星与魔鬼脚印入口

- 水星附近有**小行星带**；魔鬼脚印的入口坐标位于这一带。
- 进入需要三件套：**坐标（黄金魔方/乌拉拉）＋ 一艘扛得住的船 ＋ 认路的驾驶员**。

### 2.7 第一季未访问、但世界设定里存在的天体

| 天体 | 状态 |
| --- | --- |
| **木星** | 第一季未出现。本作暂时留白，可作为后期舞台（电影版的“大赛赛场”已排除，见附录） |
| **土星／海王星等** | 官方未展开；属于可自由填写的空间 |
| **亚亚罗** | 已毁的故国，不在太阳系内（见 3.1） |

## 三、太阳系外：故国与传说

### 3.1 亚亚罗

- 咕咚的母国，已毁灭。
- 关键技术：**空间跳跃装置**（可星系间跃迁），被咕咚卖掉换研究经费。
- 结局：被海盗/银河眼攻破，全民被蓝眼带走，仅咕咚被臣民用兔子药送出。
- **写作空间极大**：被掳走的亚亚罗人如今在哪？是否成为银河眼的实验体/劳工？

### 3.2 西亚特星

- 十二年前米龙在此“击溃”黑旗，成为英雄。
- 可写成“英雄神话的诞生地”：雕像、纪念馆、被剪辑过的历史。

### 3.3 八极星

- 八极天发源地；重力/环境极端，适合苦修。
- 米龙二代在此修炼约九年。

### 3.4 米多星【推测/衍生】

- 米龙兄妹的故乡，花田；被罗罗乌人的战火摧毁。
- 妹妹米吉在此与哥哥失散。

### 3.5 雪流星

- 不是“地点”，而是一种**会移动的星体群**：成群漂移、在过去与现在的时间中穿梭、能把曾经遇难的人带回家。
- 星学会的终极研究目标；笛亚父母未完成的使命。
- **写作提示**：这是全作最“软科幻”的设定，也是最好的长篇引擎——它让“复活/重逢”有了代价与规则（时间、位置、代价）。

## 四、未知区与终点

### 4.1 魔鬼脚印

- **性质**：全部由天然虫洞组成的航线，连接太阳系与歌罗星系。
- **危险**：空间撕裂、时间错乱、引力乱流；普通飞船进入即毁。
- **封锁**：星际联盟关闭坐标；银河眼追杀知情者、销毁相关记录。
- **名字由来**：麦林走过的航线，后人称“魔鬼的脚印”。
- **通行条件**：黄金魔方→乌拉拉→坐标；一艘扛得住虫洞的船；一个真正认路的驾驶员（第 20 集起的主线任务）。

### 4.2 歌罗星系（哥罗）

- 巨型黑洞所在地；彩虹海位于黑洞深处。
- 黑洞会吞噬生命、物质、甚至光——**“最狂热的冒险者也不愿提及的危险名词”**。

### 4.3 彩虹海

- **传说**：宝石遍地、黄金在河里流淌、上万种颜色的彩虹横跨天空，到达者可以实现任何愿望。
- **真相**：官方从未正面确认。这是全作最大的留白，本作已作出裁决（见 [09 正史裁决书](09-正史裁决书.md)）。
- **写作建议**：即便定了真相，也要让**角色们各自相信不同的版本**——传闻、谎言、教义、商业包装，四种叙述并存。

## 五、地图图例与读图法

星图（[assets/星游记星图.svg](../assets/星游记星图.svg)）采用三层结构：

| 图层 | 含义 | 视觉 |
| --- | --- | --- |
| 内圈 | 太阳系（联盟区） | 蓝色同心轨道 |
| 中圈 | 独立区/边境 | 黄色虚线带 |
| 外圈 | 未知区（魔鬼脚印、歌罗星系） | 紫黑渐变 + 红色警戒线 |

图上的**红线**是主角实际航线；**灰色虚线**是已封锁/未通行的旧航线；**红色叉号**是银河眼封锁点；**金色节点**是彩虹石/关键道具所在地。

## 六、原创地点插入指南

想加新星球，优先填这些“地理空隙”：

| 空隙 | 建议设定 | 冲突风险 |
| --- | --- | --- |
| 地球—月球之间 | 太空电梯残骸、走私空间站 | 低 |
| 火星—天王星之间 | 独立区的中立贸易站 | 低 |
| 泰坦星周边 | 采冰船队、甲烷海盗（可与“泰坦水被抽干”接上） | 低 |
| 火星深层 | 罗罗乌族更古老的战场遗迹、被掩埋的战神兵器 | 中（勿改罗罗乌传承规则） |
| 魔鬼脚印内部 | 被虫洞吞掉的文明残骸、时间错乱的“幽灵船” | 中（需遵守虫洞规则） |
| 歌罗星系外围 | 星学会的前哨站、麦林远征队的营地 | 中（勿正面写彩虹海真相，留给 09） |
| 亚亚罗故地 | 被掳子民的流放星、抵抗组织 | 低（官方留白） |

**命名风格**：原作星球名偏“音译+神话/地理”（亚亚罗、西亚特、泰坦、歌罗、米多、八极），组织名偏“意象+器官/颜色”（银河眼、五色眼、黑旗、星学会、五角军团）。新地名建议：两到四个字、可音译、带一点异域感，避免“XX 星系联盟共和国”这类冗长命名。
