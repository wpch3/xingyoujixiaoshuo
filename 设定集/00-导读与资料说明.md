# 00 导读与资料说明

## 0. 正史宣告（2026-11 修订）

**本作只承认一个底座：2011 年电视动画《星游记》第一季（1–26 集）。**

- 《星游记之风暴法米拉》（2017）、《风暴法米拉 2》（2020）：**不作为正史，不采用**。资料移入 [附录](../附录/非正史资料-风暴法米拉与冲出地球.md) 备查。
- 《冲出地球》（2022）：**平行宇宙重制，不采用**。
- 第一季之后的一切（蔓影术之后、彩虹海真相、红眼身份……）：**由本作自行裁决与书写**，见 [09 正史裁决书](09-正史裁决书.md)、[10 原创设定与谜题库](10-原创设定与谜题库.md)。

理由很简单：电影版换掉了原作的叙事逻辑——第一季问的是“所有人都说不可能，你还要不要去”，电影问的是“谁能拿到引擎、谁背叛谁”。前者能长出小说，后者只能长出一季综艺。

## 1. 这套资料解决什么问题

写《星游记》同人，最容易死在三个地方：

1. **把设定写飞**——随手给角色加彩虹石、加星球、加“宇宙第一”，读者立刻出戏。
2. **人物 OOC**——麦当说出一句精算的台词，咕咚突然沉稳老练，笛亚变成恋爱脑。
3. **接不上原作**——忘了蔓影术、忘了黄金魔方、忘了地球还被封着。

这套资料按「**正史 → 世界 → 事件 → 人 → 地 → 裁决 → 原创 → 写法**」组织。

## 2. 可信度分级（修订版）

- **【正史】**：第一季剧集内明确出现（台词、画面、片头片尾信息）。
- **【整理】**：百科／维基／粉丝 Wiki 对第一季的汇总。通常可靠，但会互相抄错。
- **【推测】**：粉丝考据与二创惯例。**在本作中，推测可以被采纳，也可以被推翻——由 [09](09-正史裁决书.md) 统一裁决。**
- **【原创】**：本作新增的设定、谜题、人物。全部登记在 [10](10-原创设定与谜题库.md)。
- `⚠️`：已知矛盾点，见 [05 未解之谜与考据](05-未解之谜与考据.md)。

## 3. “官方没回答”是资产，不是漏洞

第一季只拍了 26 集（原定 52 集），结尾停在红眼施下蔓影术。这不是“没做完”，对我们来说这是**空白的所有权**：

- 官方说麦林是“红魔鬼”、彩虹海是“最大的谎言”——**这是角色的说法，不是作者的说法**。谁在传播这个说法？为什么？
- 官方从没解释彩虹石从哪来、雪流星的规则、乌拉拉为什么是眼睛形状、五色眼为什么缺三席。
- 这些空白正好可以做成小说的**主线谜题**。

处理方式见 [09 正史裁决书](09-正史裁决书.md)：我们先列命题，再判真伪，再决定“由谁、在第几卷、以什么代价揭晓”。

## 4. 本资料库的边界

1. 没有一手分镜脚本。逐集摘要来自公开分集简介与剧情讨论，细节可能有出入，引用台词请以原片为准。
2. 第二季从未播出，第 27 集只有传闻，不作为依据。
3. 战力数据（宇宙第几强者）是粉丝整理，本作只让角色“说”，不让旁白“定”。
4. 译名多版本（唐·伍德/唐伍德、菲利/菲力、辛夕娅/辛西娅）。本作统一用法见 [05](05-未解之谜与考据.md)。

## 6. 一句话提醒

《星游记》最珍贵的不是设定多大，而是它的**情感逻辑极干净**：每个人都在守护一个“不值得守护的承诺”。

设定可以扩，谜题可以加，**但这根线不能断**。断了，就只是换了皮的打怪文。
