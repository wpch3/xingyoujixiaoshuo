# 01 世界观总纲（第一季正史版）

> 底座：2011 电视动画第一季 1–26 集。电影版内容一律排除。
> 本文回答四个问题：这个宇宙长什么样？它经历过什么？人为什么会强？谁在统治它？

---

## 一、世界基调与母题

### 1.1 一句话内核

**在一个把希望称为“谎言”的宇宙里，还有人愿意为谎言起飞。**

### 1.2 四组母题（写小说时的情感坐标系）

| 母题 | 具体表现 | 代表 |
| --- | --- | --- |
| 谎言与相信 | 彩虹海被全宇宙认定为史上最大骗局；相信它的人被嘲笑 | 麦林 / 麦当 |
| 约定 | 拉过勾的事就一定要做到；代价可以是性命 | 麦当与父亲 |
| 家与守护 | 臣民把国王变成兔子送出星球；父亲把儿子留在地球上 | 咕咚 / 麦林 / 米龙 |
| 希望与照亮 | “有绝望的地方，就有希望产生” | 星学会 / 笛亚 |

### 1.3 世界的底色：不是“太空歌剧”，而是“太空市井”

《星游记》的宇宙高度发达，却**没有被写成冰冷的技术乌托邦**。它的质感更接近“港口城市 + 大航海时代 + 老式电视台”：

- 有宇宙大饭店、老城区第七街、马戏团、黑市海湾、地下格斗场；
- 有通缉令、黑市船票、走私零件、海盗的拍卖行；
- 有偷渡、绑架、奴役孤儿、用孩子当“鱼饵”的海盗；
- 也有把孩子举过头顶放风筝的母亲。

写小说时，**多写码头、饭馆、后台、候场区、维修棚**，少写舰桥与全息投影，味道就对了。

## 二、宇宙结构

### 2.1 三大星区【整理】

原作把宇宙政治地理划为三个圈层：

| 星区 | 含义 | 秩序 | 剧情功能 |
| --- | --- | --- | --- |
| **联盟区** | 加入星际联盟的星系 | 有政府、有执法官、有贸易与航线 | 安全区，也是官僚与妥协的发生地 |
| **独立区** | 保持中立的星系与星球 | 自治，法律薄弱 | 灰色地带，适合放原创势力 |
| **未知区** | 被海盗与神秘势力控制的区域，**魔鬼脚印经过此处** | 无秩序，弱肉强食 | 真正的冒险舞台 |

> 这个三分法极其好用：**主角每深入一层，规则就少一层。**

### 2.2 空间结构示意

```
【联盟区】太阳系 ── 地球 · 月球 · 火星 · 天王星 · 泰坦星 · 水星 · 冥王星（其余行星未展开）
     │
     ├─ 旧航线已被星际联盟关闭
     ▼
【独立区】中立星系 · 自由港 · 灰色地带（本作原创的主要舞台，见 10）
     │
     ▼
【未知区】黑旗主基地（传说）
     └─ 魔鬼脚印（天然虫洞航线，唯一通路）
            │
            ▼
        歌罗星系（巨型黑洞）
            │
            ▼
        彩虹海（黑洞深处 · 传说之地）
```

### 2.3 关键天体与区域

| 名称 | 性质 | 第一季中的说明 |
| --- | --- | --- |
| **太阳系** | 故事起点 | 地球（禁飞）、月球（嫦娥/月树）、火星（塔尔西斯/黄泉湾/罗罗乌隐居地）、天王星（星学会/乌拉拉）、泰坦星（泰坦水）、水星（红眼曾把火星认成水星；魔鬼脚印入口在其附近【整理】）、冥王星（未展开） |
| **魔鬼脚印** | 自然虫洞航线 | 全部由天然虫洞组成，极度危险；通往彩虹海的唯一路径。坐标被星际联盟关闭、被银河眼封锁 |
| **歌罗星系**（亦作哥罗） | 巨型黑洞所在地 | 彩虹海位于其黑洞深处；进入需要坐标与能抗住虫洞的船 |
| **彩虹海** | 传说之地 | 宝石遍地、黄金成河、上万色彩虹横跨天空，抵达者可实现任何愿望。**是否真实存在，是全作的核心悬念** |
| **亚亚罗** | 已毁灭星球 | 咕咚的母国；因国王卖掉“空间跳跃装置”而被攻破，全民被掳走 |
| **西亚特星** | 米龙成名地 | 十二年前米龙在此“击溃”黑旗，被奉为英雄 |
| **八极星** | 修行地 | “八极天”格斗术的发源地；米龙二代在此修炼 |
| **米多星** | 米龙兄妹故乡【推测】 | 花田、战争、妹妹米吉被星际联盟救走 |
| **泰坦星** | 补给站 | 可作为燃料的“泰坦水”；原始森林与史前巨兽 |

> **空白区**：木星、金星、土星、海王星等在第一季中没有实质展开。它们不是“不存在”，而是**留给我们写**——但新增内容必须登记在 [10 原创设定](10-原创设定与谜题库.md)，且不得与第一季冲突。

### 2.4 空间技术

- **常规航行**：飞船 + 引擎，可在星系内自由通航；需要燃料、空气、维修。
- **虫洞航行**：魔鬼脚印由天然虫洞组成，普通船进去就是送死；能走这条线的船极少，且需要精确坐标。
- **空间跳跃装置**：亚亚罗的国宝级技术，可星系间跃迁；被咕咚卖掉，后落入银河眼之手（第一季台词明示）。
- **联盟航线管制**：星际联盟可以“关闭坐标”，等于从官方层面抹掉一条路。

> ⚠️ “进入魔鬼脚印需要专门的引擎”是电影版设定，本作**不采用**。第一季的条件只有三个：**坐标、船、敢开的驾驶员**。具体规则见 [09 正史裁决书](09-正史裁决书.md)。

## 四、力量体系

### 4.1 彩虹石：这个世界唯一的“超能力”

**定义【正史】**：彩虹石是宇宙中极为稀有、硬度极高的宝石。拥有它的人被称为 **“自由者”**。彩虹石会**根据持有者的性格**赋予其相应的能力。

**关键性质**

1. **不可复制**：比钻石更稀有，一枚石头只认一个主人。
2. **性格决定能力**：不是抽卡，是“你是什么样的人，就得到什么样的力量”。**能力必须是人设的隐喻。**
3. **可进化**：基础 → 增强 → 超强 三个等级【整理】。
4. **可被针对**：沙丁的能力对其他自由者无效；蔓影术能侵蚀自由者的意识；彩虹石也存在“失去力量”的状态（笛亚绝望时）。
5. **可以是装置核心**：以彩虹石为核心的装置能提供科学无法解释的能量。

### 4.2 三大系【正史设定解说】

| 系 | 原理 | 第一季例证 |
| --- | --- | --- |
| **强化系** | 强化自身某种能力 | 麦当——“大饭店”是对厨师能力的强化；卡利亚——磁力 |
| **契约系** | 与某种自然力量订立契约，借用其力量 | 笛亚——“空间契约”；红眼——“影子契约” |
| **灵力系** | 获得精神类超能力：催眠、幻象、感知等 | 蓝眼——音波（【整理】归入灵力系） |

> ⚠️ 早期宣传另用「战斗系／契约系／转化系」三分法。本作统一采用**强化／契约／灵力**，把“转化”（如嫦娥把药力转为攻击）视为强化系的变体。

### 4.3 第一季已知自由者

| 人物 | 石头位置/颜色 | 系 | 能力 | 备注 |
| --- | --- | --- | --- | --- |
| 麦当 | 右手腕护腕，红色 | 强化 | 把身体/食物实体化、硬化，以烹饪招式战斗 | 母亲辛夕娅的血脉另有秘密 |
| 笛亚 | 蓝绿色 | 契约 | 空间契约：交换、凝固、壁垒、禁闭 | 绝望时失去力量 |
| 红眼·罗曼 | 暗红 | 契约 | 影子契约：影子出手、影子冲击、影兽、**蔓影术** | 蔓影术会把人变成“影子人” |
| 卡利亚 | — | 强化 | 万能磁力、南极风暴（操纵金属） | 火星盗贼团首领 |
| 嫦娥 | — | 强化（转化） | 把药力变成攻击力 | 月球炼丹师，银河眼卧底 |
| 克拉 | — | 强化 | 钢化身躯、爆破术、炼钢术、火药鸦、火药云 | 蓝眼部下，屠灭星学会 |
| 沙丁 | 森蓝 | 灵力/契约 | “第二大脑”：暂时控制一个人的躯体，**对自由者无效** | 五角军团首领 |
| 唐·伍德 | — | 灵力/契约 | 雨伞摇点：二十四节气、六道轮回（骰子点数决定强弱）【整理】 | 星际联盟执法官 |

> **五色眼的其余三席**（紫、白、黄）在第一季中只有“席位”，没有人物。本作保留席位，人物与能力自行设定——见 [10](10-原创设定与谜题库.md)。

### 4.4 非彩虹石体系

- **八极天**：传说中的最强格斗术，共八式，人类可通过极端磨练习得。代表：米龙二代、八极天祖师。
- **罗罗乌战神兵器**：把全身力量放出并附着于兵器，形成实体（角盾、大角盾、角剑、战靴、战锤）。
- **科技装备**：机械义肢、战斗服、飞船武装、空气接收器。
- **种族天赋**：罗罗乌人的体魄、咕咚的怪物合体、歌罗人的“逆熵走直线”（本作原创，见 10）。

### 4.5 代价与限制（防止战力通胀）

| 能力 | 代价/限制 |
| --- | --- |
| 麦当的招式 | 发动时不能说话、不能呼吸；过后全身无力；超载有身体爆炸风险 |
| 空间契约·凝固 | 同归于尽型，中断传送并把双方锁进空间裂缝 |
| 蔓影术 | 不可逆地吞噬思想与意识，最终变成无意识的“影子人” |
| 沙丁的第二大脑 | 一次只能控制一个生命，且对自由者无效 |
| 八极天 | 纯肉体，无远程手段；“金色天际线”一天只能用一次 |
| 蓝眼的音波 | 需要媒介（琴弦/空气），在真空或静音环境中削弱【原创补全】 |

> **写作守则**：任何新能力都必须写清“**它拿走了什么**”。

## 六、势力

### 6.1 银河眼（Galactic Eye）

**性质**：银河系最大的集团组织，**在星际联盟大会中拥有合法席位**，有自己的外交部门与武装。阴险、逐利、以“秩序”之名行垄断之实。

**目的【整理】**：控制大量星球、进行实验；阻止任何人进入魔鬼脚印／彩虹海。

**组织结构（第一季版）**

```
主脑（未露面）
 └─ 五色眼（最高干部）
     ├─ 红眼·罗曼（影子契约）
     ├─ 蓝眼（音波；克拉上级；金牙＋鹦鹉帽）
     └─ 紫眼 / 白眼 / 黄眼（席位空缺，本作自定）
 └─ 经理人（中层干部）
     ├─ 克拉（特攻部门）
     └─ 赛璐珞（地球经理人，实力极弱）
 └─ 基层
     ├─ 大头钉（量产战斗单位，口头禅“嘿哈”）
     └─ 鼹鼠部队
 └─ 部门：外交、特攻、科研、飞船焚厂
```

**手段**：禁飞令、销毁飞船、通缉、绑架、灭门、实验、垄断航线与信息。

### 6.2 星际联盟

**性质**：各星系政府联合组成的联盟，维持星际和平与贸易，拥有星际特警/卫队，设执法官、总督等职。

**特征**

- 有大会、有席位、有程序——**因此永远慢一步**。
- 会救人也通缉人：唐·伍德救下麦当，随后又以“不配合”通缉他。
- 内部并非铁板一块，对银河眼的态度从纵容到警惕。

**代表**：唐·伍德、星际联盟卫队、各地执法官。

### 6.3 星学会

**性质**：位于天王星的星学家研究机构，以探索太空为最高追求，同时为冒险者提供导航服务。彩虹海事件后神秘解散（实为被银河眼血洗）。

**信条【正史】**：
> “星学家的使命，就是让人们不再恐惧天空，为每个旅行的人照亮回家的路。”

**遗产**：盖亚、笛亚的父母、笛亚、黄金魔方、乌拉拉、雪流星传说。

### 6.4 黑旗（太空海盗）

**性质**：太空海盗联盟，传说主基地位于魔鬼脚印所在的未知区。拥有七大舰队，曾与麦林正面冲突并被其单独对抗。

**分支**

- **黑旗本部**：阿西欧（策划米龙骗局的海盗）。
- **火星盗贼团**：卡利亚（磁力自由者，贪婪，曾败于麦林）。
- **五角军团**：沙丁（第二大脑，野心是控制战神之子），部下有泥浆骑士、电鳗弗兰克等。
- **零散海盗**：绑架咕咚的火星海盗、以孩子为“鱼饵”的人口贩子。

### 6.5 罗罗乌族

**性质**：宇宙最好战的种族，世代以战争生存，曾随大战神库撒侵略数十个星系。战后一部分隐居于火星深处的农田，试图摆脱战争宿命。

**核心设定**

- **战神兵器**：角盾、大角盾、角剑、战靴、战锤。
- **战神守护者**：多个罗罗乌人合体，战力倍增。
- **金色牛角 / 战神之子**：将所有罗罗乌人融合为一人，战力直逼大战神库撒。牛角由罗罗乌王代代相传；若王意外身亡，会在最强的战士身上重生。
- **格格斯**：没有战斗潜质、却拥有“微笑”的战神之子，被老罗罗乌王选定为继承者——**和平的象征**。

## 七、社会生态

1. **禁飞令**：地球被银河眼设为禁飞区，飞船被销毁/送进焚毁炉，连风筝都会被导弹击落。**“飞行”在这个世界是一种政治行为。**
2. **航线管制**：星际联盟关闭坐标，等于抹掉一条路；能拿到坐标的人就是全宇宙的目标。
3. **地下格斗**：格斗螺旋（火星地下竞技场），以命相搏，输赢决定自由。
4. **通缉与赏金**：联盟通缉令、海盗悬赏、赏金猎人并存。
5. **孤儿与奴役**：黑旗奴役孤儿、用孩子当“鱼饵”攻陷对手的同情心。**全作最黑暗的一层。**
6. **信息垄断**：银河眼不只封路，也封消息。【原创补全：它有自己的“公告网”，新闻发布即判决。】

## 八、写作时必须守住的 10 条世界规则

1. 彩虹石稀有，**不要批量发石头**。
2. 能力必须对应性格，**不要给角色“万能技”**。
3. 每次用大招都要付代价（身体、寿命、同伴、暴露）。
4. 银河眼是合法组织，**不能写成单纯的黑帮**；它的可怕在于“合规”。
5. 星际联盟不是救世主，它讲程序、讲利益、慢半拍。
6. 魔鬼脚印必须难进：**坐标 + 船 + 驾驶员**，三者缺一不可。
7. 太空需要空气接收器；**不要在真空里正常呼吸**。
8. 飞船有燃料、有维修、有折旧；**不要瞬移式赶路**。
9. 通缉令与公告网会把主角的行为放大成公共事件。
10. 任何“奇迹”都要先让人绝望一次，**否则不叫奇迹，叫外挂**。
