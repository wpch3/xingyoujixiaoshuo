## 一、为什么不采用

| 维度 | 第一季（2011） | 《风暴法米拉》系列 |
| --- | --- | --- |
| 故事类型 | 少年冒险 + 人情剧 | 竞技赛事 + 阴谋剧 |
| 冲突来源 | “所有人都说不可能，你还要不要去” | “谁拿到奖品、谁背叛谁” |
| 战力 | 克制；五色眼不可战胜，只能局部取胜 | 膨胀；新角色轮番登场、能力叠代 |
| 主角位置 | 唯一的发动机 | 被赛事与群像稀释的参赛者之一 |
| 情感落点 | 约定、家、父与子 | 身世、阵营、站队 |

> 一句话：**第一季讲“人为什么飞”，电影讲“谁能拿到引擎”。**

## 二、《风暴法米拉》（2017）资料留存

### 2.1 设定

- 木星举办全宇宙直播的竞技大赛“风暴法米拉”，创办者为太阳系最大传媒总裁 **梅帝奇·法米拉**。
- 奖品是唯一能进入魔鬼脚印的飞船引擎 **“朱庇特之心”**。
- 主角团组队名：“国王与随从”队。

### 2.2 新角色

| 角色 | 设定 |
| --- | --- |
| 极光 | 方糖十字星队队长、卫冕冠军、星际赏金猎人；灵力系“四维猎手”；对笛亚有好感 |
| 乙太 | 方糖十字星队队员、宇宙第一理疗师；如来秘术、六臂；塔罗牌“节制” |
| 洛奇 | 方糖十字星队队员 |
| 梅帝奇·法米拉 | 传媒总裁、大赛创办者；窥觑黄金魔方；粉丝推测为“紫眼” |
| 贝塞克 / 麦金塔 | 大赛主持人（摄影 / 口才） |
| 板栗兄弟 | 参赛选手，首轮淘汰 |
| 白眼 | 五色眼之一，冰系，“冰雪暴” |

### 2.3 剧情

麦当一行赴木星参赛 → 第一场蔓影术发作、险胜 → 第二场换队长、笛亚明面叛变 → 麦当用身世秘密换复活赛资格 → 笛亚广播“黄金魔方在我手上” → 结束。

### 2.4 塔罗牌设计

官方曾发布塔罗风格人物卡：麦当＝愚者（0），乙太＝节制（XIV）。**属于电影版的美术母题，不进入本作正史。**

## 三、《风暴法米拉 2》（2020）资料留存

### 3.1 新角色

| 角色 | 设定 |
| --- | --- |
| 鲁格（不死鬼） | 白眼麾下经理人；自身与对手分解为方块、重组，近乎不死 |
| 恕 | 参赛者；腿法“毒刺”“蜂圆舞”；粉丝推测为米龙之妹米吉 |
| 艾瓦女王 | 托纳提人的女王，可变形为小机器人；唤醒亚登的钥匙 |
| 亚登 | 传说中的王者 / 人形战争机器；曾击败大战神库撒；封印于木星 |
| 加特林 | 银河眼干部；控制/压制型 |
| 冈盾 | 冥王星“巴士地狱”的牛头人酋长；被红眼救出 |
| 南风总督 | 星际联盟高层，主张对银河眼强硬 |

### 3.2 剧情

麦当赢下复活赛 → 与恕、艾瓦组队 → 极光身世（父亲是说书人，讲“王者亚登”的故事）→ 梅帝奇与白眼翻脸 → 白眼用亚亚罗跃迁装置突袭、冰封木星、掳走艾瓦 → 鲁格屠杀 → 米龙参战被加特林压制 → 众人合力击败鲁格 → 红眼施“蔓影术·吞噬”。

### 3.3 结局悬念（第三部未制作）

麦当的蔓影术能否解除、木星冰封、亚登将醒、红眼叛变后的阵营、梅帝奇是否为紫眼、极光/恕/米龙是否入队。

## 四、《冲出地球》（2022）资料留存

**官方定位：平行宇宙。** 与第一季不兼容。

| 项目 | 第一季 | 《冲出地球》 |
| --- | --- | --- |
| 地球处境 | 因彩虹海事件被禁飞 | 陨石雨毁掉大半个地球，沦为废土 |
| 银河眼 | 银河系巨型集团 | 来自昂撒星系的外星高等势力 |
| 封锁装置 | 禁飞令、飞船焚毁炉 | 天墙计划（永不开合） |
| 真实目的 | 阻止人们进入魔鬼脚印 | 把地球改造成“再生球/戴森球”抽取能量 |

| 麦当的力量 | 彩虹石（食物系） | 多功能能量手镯 |
| 咕咚 | 兔子形态 | 棒棒糖切换人形/兔形 |
| 熊猫阿姨 | 武林高手 | 普通家庭主妇 |

**剧情概要**：陨石雨后银河眼建天墙、禁飞；麦当与芸豆偷零件，遇前天墙设计师牧雷；银河眼杀手沙无赦追杀；天墙启动，真相是戴森球；查木坤被逼弑父后反抗；麦当吸能击败连雾；天墙解体，全城放风筝。

**角色**：芸豆、牧雷、连雾博士、沙无赦、查木坤、渣古。

## 五、可回收的“零件”（不搬设定，只搬装置）

如果你将来想用类似桥段，可以**用自己的世界逻辑重建**，而不是进口这些角色与地点：

| 装置 | 原作中的形态 | 我们的重建方向（见 [10 原创设定](../设定集/10-原创设定与谜题库.md)） |

| 竞技赛 | 风暴法米拉、朱庇特之心 | “星图竞逐”：独立区船队跑半愈合的旧航路，赢家取得航权与测绘数据 |

| 竞技场 | 木星赛场 | 独立区的“沉船斗技场” |
| 冰系强者 | 白眼 | 五色眼“白眼”席位——席位保留，人、能力、阵营全部自设；**“一挥手冰封行星”不采用** |
| 分解能力 | 鲁格 | “熵化型彩虹石”：当场不收费，账转给下一位持有者（见 [10](../设定集/10-原创设定与谜题库.md) O-06） |

> 记住：**可以借结构，不能借答案。** 一旦你用了别人的谜底，你的故事就不再是你的了。
